## Math

Inline math goes between single dollar signs, like $\theta \in \mathbb{R}^d$. Display math goes between double dollar signs. The gradient descent update with learning rate $\eta$ is

$$
\theta_{t+1} = \theta_t - \eta \, \nabla_\theta \mathcal{L}(\theta_t)
$$

The figure above minimises $\mathcal{L}(x) = \tfrac{1}{4}x^4 - x^2 + 0.3x$, which has two minima. Which one you land in depends on where you start and how large $\eta$ is.

## Code

Fenced code blocks are syntax-highlighted in both themes:

```python
def gradient_descent(grad, x0, lr=0.1, steps=100):
    x = x0
    for _ in range(steps):
        x = x - lr * grad(x)
    return x

grad = lambda x: x**3 - 2 * x + 0.3
print(gradient_descent(grad, x0=2.1))  # ≈ 1.33
```

Inline code looks like `lr=0.1`.
